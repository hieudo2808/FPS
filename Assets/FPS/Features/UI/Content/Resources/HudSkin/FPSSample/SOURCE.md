# FPSSample HUD sprites

Source: https://github.com/Unity-Technologies/FPSSample

Copyright (c) 2018 Unity Technologies ApS. Licensed under the Unity Companion License for Unity-dependent projects; see LICENSE.md.

Ten selected HUD images are provided as single UI sprites. Six PNGs are copied unchanged. Four TIFFs (mouse buttons, bullets and infinity) are converted losslessly to PNG, preserving dimensions and decoded RGBA pixels. Original paths, source SHA-256 hashes and imported PNG hashes are recorded in source-assets.json.

Nine images are integrated into the FPS HUD through Resources/HudSkin/FPSSample. UI_Hud_Inifity remains reserved. The folder was moved with AssetDatabase.MoveAsset, preserving its imported GUIDs. No source HUD prefab, script, portrait or weapon-specific icon is included.
