# Enemy sounds

Derived from CC0 sources, downloaded 2026-11-14 with the user's approval; trimmed, faded, peak-normalised,
downmixed to mono 16-bit WAV. Crediting the authors is optional.

Role split of the zombie pack was made by length (the pack has no labels): shortest = hurt, longest = death,
loud mid-length = attack, the rest = idle growls. Rename/move files and re-run Tools/FPS/Audio/Build All to change it.
