## Trust boundaries

- Codebase Memory is static code/config analysis. It can miss runtime behavior, reflection, generated code, Unity serialization, and constructs in parse-partial files.
- The Unity graph is an AssetDatabase/Editor snapshot. It covers assets, prefabs, the scenes loaded during export, Animator parameters/layers, and serialized object references; it is not a runtime execution trace.
- Exclusion is deliberate and is not evidence that a relationship does not exist.
- Always check graph timestamps, Git revision/status, coverage, and relevant source/Editor state before making negative or destructive claims.
